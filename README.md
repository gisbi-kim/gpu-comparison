# GPU와 AI 시스템 비교

GPU 및 AI 시스템의 하드웨어 사양과 공개 벤치마크를 비교하고 관련 개념을 설명하는 한국어·영어 정적 웹 페이지입니다. 페이지의 수치와 해설은 원본 파일의 작성 시점 자료이며, 최신 사양이나 동일 조건의 직접 비교를 보장하지 않습니다. 각 수치의 조건과 출처는 페이지에서 확인하세요.

## 사용

GitHub Pages에서 사이트를 열거나 `index.html`을 브라우저에서 직접 열면 됩니다. 별도의 빌드 과정이나 서버가 필요하지 않습니다. 페이지에는 비교 차트, 학습 자료, 용어 설명, 언어 및 테마 전환 기능이 포함되어 있습니다.
